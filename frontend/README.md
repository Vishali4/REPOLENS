# RepoLens Frontend

A modern, high-performance developer intelligence interface built with **React**, **Vite**, **Tailwind CSS**, and **Lucide React**.

---

## Available Routes

| Route | Description |
| :--- | :--- |
| `/` | Landing page with Hero, futuristic architecture visual, features, and workflow |
| `/dashboard` | Repository overview with stat cards, summary, language chart, and file tree |
| `/repository` | Detailed repository metadata, key manifest files, and README preview |
| `/analysis` | Code quality scorecards (87%), complexity, and RepoLens Insights |
| `/dependencies` | Searchable and filterable dependency health table |
| `/architecture` | Interactive component topology and architectural layer descriptions |
| `/assistant` | ChatGPT-style developer assistant with repository context and suggestions |
| `/settings` | Theme, default branch, animations, and compact mode preferences |

## Running Locally

1. Navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
